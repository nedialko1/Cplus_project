# The C++ Generations: A **`medium.com`** Article Companion

This repository serves as the official companion code and architectural showcase for the article:
> **A Short History of C++ = the Grand Paradigm(s), the Evolutions, the REvolutions"**

## Repository Architecture & Article Sections

The directory structure directly mirrors the conceptual evolutions explored in the article:

* **`python/`** — Provide the baseline for all the algorithms explored from a C++ perspective.
* **`cpp_14/`** — The Consolidated "boilerplate" C++: smart pointers, move semantics, zero-overhead abstraction.
* **`cpp_17/`** — Reduction of the boilerplate: structured bindings, fold expressions, optional types.
* **`cpp_20/`** — Paradigm shifts and Compile-time safety: **Concepts**, Ranges, Coroutines.
* **`cpp_23/`** — Borrowed language features:  monadic error handling, lazy generation, multidimensional indexing.
